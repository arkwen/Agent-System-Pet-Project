# 📊 AI Data Visualization Agent System

Простой агент для автоматической генерации Python-кода для визуализации данных по текстовому запросу пользователя.

* **Frontend:** Веб-интерфейс написан с использованием библиотеки **Streamlit**.
* **Backend:** Асинхронный REST API веб-сервер на **FastAPI** с  валидацией данных через **Pydantic**.
* **Модель** Поддержка локального инференса через **Ollama** или интеграция с облачным агрегатором **OpenRouter API**.

---

## 🛠️ Системные требования

Перед развертыванием проекта убедитесь, что на вашем компьютере установлены:
1. **Python 3.12+**
2. Менеджер пакетов **uv** (`pip install uv`)
3. Локальный сервер **Ollama** (необязательно)

---

## 🚀 Вариант 1: Быстрый локальный запуск (через Ollama)

Полностью приватный режим, выполняющийся на вашем компьютере без отправки данных во внешние сети.

### Шаг 1: Подготовка локальной нейросети
1. Запустите приложение **Ollama**.
2. Скачайте модель, оптимизированную для задач написания кода:
   ```bash
   ollama run qwen2.5-coder:3b
   ```
3. После завершения загрузки выйдите из чата (`Ctrl + D`). Сервер Ollama продолжит работать в фоне на стандартном порту `11434`.

### Шаг 2: Установка зависимостей
Из корневой директории проекта выполните синхронизацию пакетов с помощью `uv`:
```bash
uv sync
```

### Шаг 3: Конфигурация сетевых адресов
Убедитесь, что в файле `src/agent_system_plots/agent.py` клиент настроен на локальный хост:
```python
client = OpenAI(
    base_url="http://127.0.0",
    api_key="ollama"
)
```

### Шаг 4: Запуск сервисов
Откройте два параллельных терминала в VS Code и запустите микросервисы:

* **Терминал 1 (Бэкенд FastAPI):**
  ```bash
  uv run uvicorn src.agent_system_plots.main:app --reload --port 8000
  ```
* **Терминал 2 (Фронтенд Streamlit):**
  ```bash
  uv run streamlit run src/agent_system_plots/app.py
  ```

## ☁️ Вариант 2: Гибридный запуск (OpenRouter API)

Режим, переносящий всю вычислительную нагрузку на мощную удаленную модель **Qwen 27B** через облачное API.

### Шаг 1: Конфигурация клиента
В файле `src/agent_system_plots/agent.py` переключите базовый URL на OpenRouter и укажите бесплатную модель `qwen/qwen3.8-27b:free`:
```python
client = OpenAI(
    base_url="https://openrouter.ai",
    api_key="ВАШ_СЕКРЕТНЫЙ_API_КЛЮЧ"
)
```

### Шаг 2: Запуск
Включите системный VPN на вашем компьютере (для обхода прямых сетевых блокировок к домену `openrouter.ai`) и запустите бэкенд и фронтенд аналогично инструкциям из Варианта 1 или с использованием контейнеров Docker и команды
  ```bash
  docker compose up --build
  ```
